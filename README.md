# credit_card_approvals_study

Machine Learning approach to understanding trends in financial data

## Status

Work in progresss. I recently found this kaggle competition and decided the change the scoope of the project.

## Data

Yao Yan, Walter Reade, Elizabeth Park. Predicting Credit Card Fraud. https://www.kaggle.com/competitions/playground-series-s6e11, 2026. Kaggle.

## Goal

The goal is to predict credit card fraud. My model will be evaluated on the area under the ROC curve between the predicted probability and the observed target.
